## Чому перший скріншот важливіший за інші

Він перевіряє те, що ламалося двічі й обидва рази мовчки (див. «Дві поломки, які
не падають» у README). Якщо під `multi-agent-research` **не видно вкладених**
суб-агентів, а замість одного дерева в списку лежать окремі корені — значить
проброс контексту між процесами не працює, хоча система при цьому цілком жива і
в логах чисто.

Тобто це не «скріншот для галочки», а єдина візуальна перевірка головної
інженерної частини роботи.

## Про третій

Evaluator'и заводяться ТІЛЬКИ руками: **LLM-as-a-Judge → Evaluators → + Set up
evaluator**, мінімум два з різними score type. Після створення потрібні нові
прогони і хвилина-дві очікування — оцінка виконується асинхронно.
